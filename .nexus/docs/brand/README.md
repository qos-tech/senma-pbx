# SENMA Visual Identity

**SENMA** is the master brand; **SENMA PBX** is the product.

## Palette
- SENMA Blue `#2563EB`
- Indigo `#4F46E5`
- Violet `#7C34ED`
- Lilac `#C084FC`
- Navy `#081120`
- Surface `#121826`
- Gray `#E5E7EB`

## Typography direction
- Display/brand: Orbitron SemiBold
- Interface/text: Inter

Font files are intentionally not bundled. Confirm licensing and load fonts through the project's dependency process.

## Asset status
The PNG logo files are reference exports from the approved V2 concept board. They are useful for documentation and mockups, but the final production logo should be redrawn as native vector artwork before SVG becomes the canonical source.

Use gradients mainly as accents and keep SENMA visually dominant over the PBX descriptor.
